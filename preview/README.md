# WARDEN · interface explorável

Abra `index.html` com um servidor HTTP local, por exemplo `python -m http.server 8000`, e visite http://localhost:8000/preview/. Não requer dependências npm.

Identidade: **WARDEN** · SEGURANÇA DEFENSIVA. Cor principal `#EDBC74`. Logos vetoriais: `logo.svg` (símbolo) e `brand.svg` (assinatura). Tipografia: fontes do sistema, sem recursos de terceiros.

Esta interface é uma entrega incremental. Não substitui a aplicação existente na raiz. Dados de demonstração são identificados. Nenhuma credencial é solicitada e nenhum arquivo é enviado a serviços externos.
